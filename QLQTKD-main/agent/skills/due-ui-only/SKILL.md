# MY DUE UI-only rules

- Source of truth: `ToBe_Nhom3.bpmn`; validate against `Nhom3.docx` and the event-organizing portions of `HỒ SƠ ĐẤU THẦU.docx`.
- Target: university event approval workflow for BCH Liên Chi Đoàn, BCN Khoa, Đoàn Trường, CSVC and KHTC.
- Default deliverable is editable Figma-first interface design (desktop 1440x900, mobile web 390x844); not a coded website unless explicitly requested.
- Palette: DUE blue `#075F9F`, green `#0E9045`, orange `#FE751E`; backgrounds `#FFFFFF` / `#F5F7FA`; borders `#E5E7EB`. If supplied logo has authoritative codes, those take precedence.
- Build screens/variants that cover manual decisions and their alternate/error paths; visualize service tasks as status instead of creating unnecessary forms.
- All UI copy is Vietnamese. Avoid duplicate section titles, fake data represented as real, excess shadows or rainbow cards.
- NEVER implement backend, API, database, server actions, real email, SSO, real AI decisions, live payments, or cloud integrations. All data simulated in UI.
- Do not claim Figma Design native file creation unless an actual Figma editing tool confirmed success. Prefer editable SVG if direct `.fig` is unavailable.
